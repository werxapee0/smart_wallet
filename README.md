# 💼 Smart Wallet CLI — Менеджер личных финансов

Консольное приложение на чистом Python для учёта личных финансов, контроля доходов, расходов и анализа трат по категориям.

Я сделал этот проект для практики ООП, разделения кода на модули, работы с файловой системой и валидации пользовательского ввода.

---

## 📌 Функционал

- **Доходы и расходы:** Учёт операций с указанием суммы, категории и комментария.
- **Текущий баланс:** Автоматический расчёт общих доходов, расходов и чистого остатка.
- **История операций:** Просмотр списка трат и доходов с фильтрацией по категориям.
- **Аналитика и статистика:** Процентное распределение расходов по категориям.
- **Удаление записей:** Возможность удалить ошибочную операцию по её ID.
- **Надёжное хранение:** Автоматическое сохранение данных в формате JSON с защитой от повреждения файлов.

---

## 🛠 Технологии и архитектура

- **Python 3.10+** (без сторонних зависимостей)
- **ООП (Объектно-ориентированное программирование):** разделение на модели (`models.py`), хранилище (`storage.py`) и бизнес-логику (`wallet.py`).
- **Type Hinting:** полная аннотация типов в функциях и методах.
- **Pathlib & JSON:** устойчивая работа с путями и файлами данных.
